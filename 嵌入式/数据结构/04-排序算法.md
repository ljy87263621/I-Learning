# 排序算法

## 1. 基本概念

排序是按照某个字段的大小关系重新排列数据。针对学生数据，可以按学号、姓名或成绩排序。

- **稳定排序**：关键字相等的元素，排序后相对顺序不变。
- **不稳定排序**：关键字相等的元素，排序后相对顺序可能改变。
- **内排序**：所有待排序数据可以放入内存。
- **外排序**：数据量大，需要借助外存分批处理。

稳定性只有在记录包含多个字段，且需要保留相等关键字的原有顺序时才重要。

## 2. 复杂度总表

| 算法 | 最好 | 平均 | 最坏 | 额外空间 | 稳定性 |
| --- | ---: | ---: | ---: | ---: | --- |
| 插入排序 | `O(n)` | `O(n^2)` | `O(n^2)` | `O(1)` | 稳定 |
| 冒泡排序 | `O(n)` | `O(n^2)` | `O(n^2)` | `O(1)` | 稳定 |
| 选择排序 | `O(n^2)` | `O(n^2)` | `O(n^2)` | `O(1)` | 通常不稳定 |
| 快速排序 | `O(n log n)` | `O(n log n)` | `O(n^2)` | 平均 `O(log n)` | 不稳定 |

快速排序的额外空间主要来自递归栈；如果划分极不平衡，递归深度可能达到 `O(n)`。通过随机选支点、三数取中或限制递归深度可以降低退化概率。

## 3. 插入排序

维护一个已经有序的前缀，每次取出下一个元素，从后向前寻找插入位置并向后移动较大元素。

```c
void insertion_sort(int a[], int n)
{
    for (int i = 1; i < n; ++i) {
        int value = a[i];
        int j = i - 1;

        while (j >= 0 && a[j] > value) {
            a[j + 1] = a[j];
            --j;
        }
        a[j + 1] = value;
    }
}
```

特点：

- 已经接近有序时很快，最好为 `O(n)`。
- 通过“移动”而不是交换减少无意义的数据交换。
- 插入位置在相等元素之后时保持稳定。
- 适合小规模数据或作为复杂排序的子过程。

## 4. 冒泡排序

反复比较相邻元素，逆序则交换。每一趟会把一个极值移动到未排序区间末端。

常见优化：

1. 第 `i` 趟不再比较已经归位的末尾元素。
2. 若某一趟没有发生交换，说明序列已经有序，可以提前结束。

冒泡排序容易理解且稳定，但平均和最坏情况仍为 `O(n^2)`。

## 5. 选择排序

在未排序区间中寻找最小值，放到当前区间开头，然后缩小未排序区间。

- 比较次数基本固定，最好、平均、最坏都是 `O(n^2)`。
- 交换次数较少，最多约 `n` 次。
- 原地排序，但通常不稳定：把最小值换到前面可能跨过相等元素。

我写选择排序时，会记录 `min_index`，一趟完成后再交换，而不是发现更小值就立即交换。

## 6. 快速排序

快速排序采用分治：

1. 选择一个支点 `pivot`。
2. 将较小元素放在支点左侧，较大元素放在右侧，完成一次划分。
3. 递归排序左右子区间。
4. 区间长度不超过 1 时结束。

平均情况下划分较均衡，复杂度为 `O(n log n)`；如果每次支点都是最大或最小值，递归会退化为 `O(n^2)`。

划分时必须明确：

- 支点最终落在哪个下标。
- 左右递归区间是否包含支点。
- 相等元素如何处理。
- 递归终止条件是否为区间长度 `<= 1`。

## 7. 我的排序选择依据

- 数据很少或基本有序：插入排序。
- 需要稳定且实现简单：插入排序或优化后的冒泡排序。
- 交换成本高、希望减少交换次数：选择排序。
- 一般数组排序、平均性能优先：快速排序。
- 如果我要求排序稳定，可以考虑归并排序，时间复杂度为 `O(n log n)`，代价是需要 `O(n)` 的辅助空间；如果我要求最坏时间复杂度为 `O(n log n)` 且额外空间为 `O(1)`，可以考虑堆排序，但堆排序不稳定。
