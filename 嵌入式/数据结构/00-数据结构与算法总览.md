# 数据结构与算法总览

## 1. 学习主线

数据结构可以从三个层面理解：

1. **逻辑结构**：数据之间是什么关系，例如集合、线性表、树、图。
2. **存储结构**：数据实际如何放在内存中，例如顺序存储、链式存储。
3. **操作与算法**：如何访问、插入、删除、查找、排序，以及如何分析效率。

同一种逻辑结构可以有不同的存储方式。例如，线性表既可以用连续数组实现，也可以用节点和指针实现；栈可以用顺序栈或链式栈实现。

## 2. 复杂度分析

### 2.1 时间复杂度

时间复杂度描述问题规模 `n` 增大时，算法执行次数的增长趋势，不等于某台机器上的绝对运行时间。分析时通常保留最高阶项并忽略常数：

| 典型形式 | 复杂度 | 识别方法 |
| --- | --- | --- |
| 常数次操作 | `O(1)` | 与 `n` 无关 |
| 单层完整遍历 | `O(n)` | 循环大致执行 `n` 次 |
| 每次规模减半 | `O(log n)` | `i *= 2`、二分 |
| 两层独立遍历 | `O(n^2)` | `n * n` |
| 分治且每层合计处理 `n` | `O(n log n)` | 归并、平均快速排序 |

几个容易出错的例子：

- `for (i = 1; i < n; i *= 2)`：`O(log n)`。
- `s += i`，当 `s < n` 时每轮 `i++`：因为 `s` 约为 `1 + 2 + ... + i`，所以循环次数为 `O(sqrt(n))`。
- 两个嵌套循环不一定都是 `O(n^2)`，要看内层循环的总执行次数。

### 2.2 空间复杂度

空间复杂度关注算法运行过程中额外使用的空间：

- 原地修改数组、只使用少量临时变量：通常为 `O(1)`。
- 递归调用的栈空间也要计入空间复杂度。
- 快速排序平均递归深度约为 `O(log n)`，最坏情况下可能退化为 `O(n)`。

时间和空间经常需要权衡：使用额外索引、缓存、哈希表可能节省时间，但会增加空间；顺序查找节省空间，但时间可能更长。

## 3. 常见结构的选择

| 需求 | 优先考虑 | 原因 |
| --- | --- | --- |
| 频繁按下标访问 | 顺序表、数组 | 随机访问为 `O(1)` |
| 频繁在已知位置插入/删除 | 链表 | 主要修改指针，避免搬移整段数据 |
| 后进先出 | 栈 | `push` / `pop` 在同一端 |
| 先进先出 | 队列 | `enqueue` 在队尾，`dequeue` 在队头 |
| 需要有序动态查找 | BST、AVL、红黑树 | 利用键值大小关系 |
| 平均常数时间按键查找 | 哈希表 | 哈希函数直接定位桶 |
| 小规模、实现简单的排序 | 插入、冒泡、选择 | 代码短，额外空间少 |
| 平均性能优先的比较排序 | 快速排序 | 平均 `O(n log n)` |

## 4. 复杂度速查

| 结构/算法 | 访问/查找 | 插入 | 删除 | 备注 |
| --- | ---: | ---: | ---: | --- |
| 顺序表 | `O(1)` 按下标 | 中间 `O(n)` | 中间 `O(n)` | 需要连续空间 |
| 单链表 | `O(n)` | 已知前驱时 `O(1)` | 已知前驱时 `O(1)` | 不支持随机访问 |
| 栈 | 栈顶 `O(1)` | `O(1)` | `O(1)` | LIFO |
| 循环队列 | 队头 `O(1)` | `O(1)` | `O(1)` | 需要处理回绕和满队 |
| BST | 平均 `O(log n)` | 平均 `O(log n)` | 平均 `O(log n)` | 退化后为 `O(n)` |
| AVL/红黑树 | `O(log n)` | `O(log n)` | `O(log n)` | 自动维护平衡 |
| 哈希表 | 平均 `O(1)` | 平均 `O(1)` | 平均 `O(1)` | 冲突严重时会变慢 |

## 5. 复习顺序

1. 先掌握线性表，理解顺序存储和链式存储的差异。
2. 从线性表的限制条件理解栈和队列。
3. 掌握二叉树术语、四种遍历，再学习 BST。
4. 用 BST 的退化问题引出 AVL 和红黑树。
5. 学习排序的稳定性与复杂度，再对比各算法的适用场景。
6. 最后学习二分查找、BST 查找和哈希查找的差异。

## 6. 编程时的通用检查清单

- 初始化是否成功，`malloc` 返回值是否检查。
- 空结构、满结构、只有一个元素时是否单独处理。
- 删除节点前是否保存了仍要访问的后继指针。
- 释放内存后是否还存在悬空指针。
- 下标是否越界，循环队列是否正确取模。
- 递归是否有明确的终止条件。
- 对排序算法是否说明升序/降序、稳定性和最好/平均/最坏情况。
