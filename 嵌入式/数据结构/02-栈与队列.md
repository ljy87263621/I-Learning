# 栈与队列

## 1. 栈

栈是只能在一端进行插入和删除的线性表，遵循 **后进先出（LIFO）**。

- 栈顶：允许插入和删除的一端。
- 栈底：栈顶的另一端。
- 入栈：`push`。
- 出栈：`pop`。
- 取栈顶但不删除：`top` 或 `peek`。

函数调用栈、表达式求值、括号匹配、深度优先搜索和进制转换都适合用栈建模。C 语言中的“栈内存”是内存区域的概念；栈这种数据结构是后进先出的操作规则，二者相关但不是同一个概念。

## 2. 顺序栈

```c
typedef struct {
    int *data;
    int capacity;
    int top;          // 栈顶元素下标，空栈为 -1
} SeqStack;
```

核心操作：

```c
bool stack_empty(const SeqStack *s)
{
    return s == NULL || s->top == -1;
}

bool stack_full(const SeqStack *s)
{
    return s != NULL && s->top == s->capacity - 1;
}

bool stack_push(SeqStack *s, int value)
{
    if (s == NULL || stack_full(s))
        return false;
    s->data[++s->top] = value;
    return true;
}

bool stack_pop(SeqStack *s, int *out)
{
    if (stack_empty(s))
        return false;
    if (out != NULL)
        *out = s->data[s->top];
    --s->top;
    return true;
}
```

顺序栈的入栈、出栈、取栈顶都是 `O(1)`；缺点是容量固定，除非额外实现扩容。

## 3. 链式栈

把单链表的头部作为栈顶即可：

```c
typedef struct StackNode {
    int data;
    struct StackNode *next;
} StackNode;

typedef struct {
    StackNode *top;
    int size;
} LinkStack;
```

链式栈没有固定容量上限，受可用堆内存限制；每个节点需要额外的 `next` 指针。头插和头删都为 `O(1)`。

## 4. 队列

队列是在两端操作的特殊线性表，遵循 **先进先出（FIFO）**。

- 队头：出队的一端。
- 队尾：入队的一端。
- 入队：`enqueue`。
- 出队：`dequeue`。
- 读取队头但不删除：`front`。

打印任务、消息缓冲、任务调度、广度优先搜索都可以抽象为队列。

## 5. 循环队列

直接使用数组实现队列时，如果出队后只移动 `front`，数组前面的空位可能无法复用。循环队列让下标到达数组末尾后回到开头。

我在循环队列中采用“牺牲一个位置”的约定：

- `front` 指向当前队头元素。
- `rear` 指向下一个入队位置。
- 空队：`front == rear`。
- 满队：`(rear + 1) % capacity == front`。
- 可存储元素数：`capacity - 1`。

```c
typedef struct {
    int *data;
    int capacity;
    int front;
    int rear;
} RingQueue;

bool queue_empty(const RingQueue *q)
{
    return q == NULL || q->front == q->rear;
}

bool queue_full(const RingQueue *q)
{
    return q != NULL && (q->rear + 1) % q->capacity == q->front;
}

bool queue_push(RingQueue *q, int value)
{
    if (q == NULL || queue_full(q))
        return false;
    q->data[q->rear] = value;
    q->rear = (q->rear + 1) % q->capacity;
    return true;
}

bool queue_pop(RingQueue *q, int *out)
{
    if (queue_empty(q))
        return false;
    if (out != NULL)
        *out = q->data[q->front];
    q->front = (q->front + 1) % q->capacity;
    return true;
}
```

入队、出队、取队头都是 `O(1)`。实现时最容易出错的是 `rear` 的语义：它可以表示“最后一个元素”，也可以表示“下一个空位”，两种约定不能混用。

## 6. 链式队列

链式队列需要同时维护队头和队尾：

```c
typedef struct QueueNode {
    int data;
    struct QueueNode *next;
} QueueNode;

typedef struct {
    QueueNode *front;
    QueueNode *rear;
    int size;
} LinkQueue;
```

入队时我把节点接到 `rear` 后面；出队时从 `front` 摘除节点。这里我会检查：

- 空队入队后，`front` 和 `rear` 都必须指向新节点。
- 只有一个元素的队列出队后，`front` 和 `rear` 都必须重新置为 `NULL`。
- 释放队头节点前先保存 `front->next`。

## 7. 栈与队列的经典应用

### 7.1 十进制转其他进制

不断执行 `n % base` 得到低位，再执行 `n /= base`。余数产生顺序是“低位到高位”，需要用栈反转后输出。十六进制余数 `10..15` 要映射为 `A..F`。

### 7.2 括号匹配

从左到右扫描：

1. 左括号入栈。
2. 遇到右括号时，栈空则失败；否则检查栈顶类型是否匹配。
3. 扫描结束时栈必须为空。

### 7.3 二叉树按层遍历

根节点入队；循环执行“队头出队、访问、左右孩子入队”，直到队列为空。

## 8. 复杂度对比

| 实现 | 入栈/入队 | 出栈/出队 | 空间特点 |
| --- | ---: | ---: | --- |
| 顺序栈 | `O(1)` | `O(1)` | 连续空间，容量可能固定 |
| 链式栈 | `O(1)` | `O(1)` | 动态节点，带指针开销 |
| 循环队列 | `O(1)` | `O(1)` | 连续空间，需处理容量约定 |
| 链式队列 | `O(1)` | `O(1)` | 动态节点，维护头尾指针 |
