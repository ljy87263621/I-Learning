# 线性表

## 1. 核心概念

线性表是一组具有“一对一”关系的数据元素。除首元素没有直接前驱、尾元素没有直接后继外，中间元素都有且仅有一个直接前驱和一个直接后继。

要区分：

- **逻辑结构**：元素之间的线性关系。
- **存储结构**：如何在内存中保存这些元素。
- **顺序表**：用连续内存保存线性表。
- **链表**：用离散节点保存元素，并用指针连接逻辑相邻节点。

## 2. 顺序表

### 2.1 管理结构体

```c
typedef struct {
    int *data;       // 连续存储区
    int capacity;    // 总容量
    int size;        // 当前元素个数
} SeqList;
```

使用 `size` 表示元素个数时，有效下标为 `0 .. size - 1`，比保存 `last` 下标更不容易混淆。

### 2.2 基本操作

```c
bool seq_insert(SeqList *list, int index, int value)
{
    if (list == NULL || index < 0 || index > list->size)
        return false;
    if (list->size == list->capacity)
        return false;

    for (int i = list->size; i > index; --i)
        list->data[i] = list->data[i - 1];

    list->data[index] = value;
    ++list->size;
    return true;
}

bool seq_remove(SeqList *list, int index, int *out)
{
    if (list == NULL || index < 0 || index >= list->size)
        return false;

    if (out != NULL)
        *out = list->data[index];

    for (int i = index; i < list->size - 1; ++i)
        list->data[i] = list->data[i + 1];

    --list->size;
    return true;
}
```

### 2.3 特点与复杂度

- 按下标访问：`O(1)`。
- 在尾部插入（有空间）：`O(1)`。
- 在头部或中间插入、删除：通常 `O(n)`，因为需要搬移元素。
- 存储密度高，缓存局部性好。
- 需要连续内存，扩容或缩容时可能重新申请并复制数据。

## 3. 单链表

### 3.1 节点和头结点

```c
typedef struct SNode {
    int data;
    struct SNode *next;
} SNode;
```

常用带头结点的设计：`head` 指向一个不保存有效数据的哨兵节点，真正的第一个元素是 `head->next`。这样插入或删除首节点时不需要修改头指针。

空链表判断：

```c
bool list_empty(const SNode *head)
{
    return head == NULL || head->next == NULL;
}
```

### 3.2 头插、删除和遍历

```c
void list_push_front(SNode *head, SNode *node)
{
    node->next = head->next;
    head->next = node;
}

SNode *list_pop_front(SNode *head)
{
    if (list_empty(head))
        return NULL;

    SNode *node = head->next;
    head->next = node->next;
    node->next = NULL;
    return node;       // 由调用者决定何时 free
}

void list_foreach(const SNode *head)
{
    for (const SNode *p = head->next; p != NULL; p = p->next)
        printf("%d ", p->data);
}
```

删除分为两个动作：

1. 从链表中摘除节点，修改指针关系。
2. 根据所有权决定是否 `free` 节点。

这两个动作不要混在一起，节点移动、拼接或重排时尤其重要。

### 3.3 链表销毁

释放当前节点前必须先保存下一个节点：

```c
void list_destroy(SNode *head)
{
    SNode *p = head;
    while (p != NULL) {
        SNode *next = p->next;
        free(p);
        p = next;
    }
}
```

### 3.4 循环链表

循环链表的尾节点不指向 `NULL`，而是指向头结点或首节点。带头结点的循环单链表通常这样初始化：

```c
head->next = head;
```

空表条件变为 `head->next == head`。遍历终止条件也必须改成“回到头结点”，不能再判断 `p != NULL`。

## 4. 双向循环链表

### 4.1 节点与空表

```c
typedef struct DNode {
    int data;
    struct DNode *prev;
    struct DNode *next;
} DNode;
```

带头结点的空表满足：

```c
head->prev = head;
head->next = head;
```

这种设计能用同一套逻辑处理头部、尾部和中间节点。

### 4.2 插入与摘除

在 `pos` 节点之后插入 `node`：

```c
void dlist_insert_after(DNode *pos, DNode *node)
{
    node->prev = pos;
    node->next = pos->next;
    pos->next->prev = node;
    pos->next = node;
}
```

摘除已在链表中的节点：

```c
void dlist_remove(DNode *node)
{
    node->prev->next = node->next;
    node->next->prev = node->prev;
    node->prev = NULL;
    node->next = NULL;
}
```

摘除和释放依旧是两个动作。向后遍历使用 `next`，向前遍历使用 `prev`，直到回到 `head`。

## 5. 顺序表与链表对比

| 对比项 | 顺序表 | 链表 |
| --- | --- | --- |
| 内存 | 连续 | 离散 |
| 随机访问 | 支持，`O(1)` | 不支持，查找通常 `O(n)` |
| 已知位置插入/删除 | 需要搬移，`O(n)` | 调整指针，通常 `O(1)` |
| 额外空间 | 主要是数据区 | 每个节点需要一个或多个指针 |
| 容量变化 | 可能需要扩容和复制 | 节点可动态申请 |
| 适合场景 | 访问多、修改少 | 动态变化大、插删频繁 |

## 6. 常见陷阱

- `head` 是头指针，头结点是可选的哨兵节点，两者不要混为一谈。
- 链表删除时先保存后继节点，否则释放或断开后可能丢失链表。
- 循环链表不能用 `NULL` 作为唯一终止条件。
- 双向链表修改一个方向时，必须同步修改另一个方向。
- 所有权不清晰时，容易出现重复释放或内存泄漏。
