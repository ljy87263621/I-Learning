## 最小程序

```c
#include <stdio.h>

int main(void) {
    printf("Hello, world!\n");
    return 0;
}
```

## 三个关键点

| 部分 | 作用 | 要点 |
| --- | --- | --- |
| `#include <...>` | 引入声明 | 使用库函数前包含对应头文件；头文件通常不提供实现。 |
| `main` | 进程入口 | 标准托管环境常写作 `int main(void)` 或 `int main(int argc, char *argv[])`。 |
| `return` | 结束函数并返回值 | `main` 返回 `0` 通常表示成功，非零表示失败状态。 |

## `printf`

`printf` 按格式串输出数据；一个转换说明通常对应一个实参。

```c
int count = 3;
double ratio = 0.75;
printf("count=%d, ratio=%.2f\n", count, ratio);
```

常用说明符：`%d`（`int`）、`%c`（字符）、`%s`（以 `\0` 结尾的字符串）、`%f`（`double`）、`%zu`（`size_t`）。`\n` 是换行。

## 易错点

- 函数被调用前必须已有可见声明；否则现代 C 编译器应报错或至少警告。
- 格式串与实参类型不匹配是未定义行为；编译时开启 `-Wall -Wextra`。
- `main` 的返回值由启动它的环境读取，并非“无所谓”。
