# 作用域与存储期

[[欢迎|返回索引]]

## 1. 两个不同的问题

- **作用域（scope）**：源代码中名字从哪里开始可见、在哪里结束可见。
- **存储期（storage duration）**：对象何时创建、何时销毁。
- **链接属性（linkage）**：不同源文件中同名声明能否表示同一实体。

不要把“局部变量”与“自动存储期”完全等同：块内 `static` 变量作用域局部，但拥有静态存储期。

## 2. 作用域

| 作用域     | 典型位置             | 可见范围           |
| ------- | ---------------- | -------------- |
| 文件作用域   | 所有代码块之外          | 从声明处到当前翻译单元末尾。 |
| 块作用域    | `{ ... }` 内或函数参数 | 从声明处到所在代码块结束。  |
| 函数原型作用域 | 函数声明中的参数名        | 仅该原型声明。        |
| 函数标签作用域 | `label:`         | 整个函数。          |

内层同名声明会**遮蔽**外层名字：

```c
int value = 1;
void f(void) {
    int value = 2;  // 遮蔽文件作用域的 value
    (void)value;
}
```

减少作用域有助于降低命名冲突，但不要为了缩小作用域而牺牲变量生命周期的正确性。

## 3. 存储期

| 存储期 | 对象示例 | 生命周期 |
| --- | --- | --- |
| 自动 | 普通局部变量、形参 | 进入声明所在块到离开该块。 |
| 静态 | 全局变量、`static` 局部变量、字符串字面量 | 程序启动到程序结束。 |
| 线程 | `_Thread_local` 对象 | 线程创建到线程结束。 |
| 动态 | `malloc` 得到的对象 | 分配成功到 `free`。 |

文件作用域对象与 `static` 局部对象未显式初始化时会被零初始化；自动对象未初始化时值不确定。

## 4. 链接属性与 `static`

```c
int shared;             // 外部链接：可被其他翻译单元用 extern 声明引用
static int private_id;  // 内部链接：仅当前翻译单元可见

void tick(void) {
    static unsigned calls;  // 块作用域 + 静态存储期
    ++calls;
}
```

- 文件作用域普通函数和对象默认通常具有外部链接。
- 文件作用域 `static` 赋予内部链接，适合模块私有实现。
- 块作用域 `static` 改变的是存储期，不会让名字跨出代码块。
