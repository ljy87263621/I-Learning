# 数据类型、运算符与控制流

## 1. 基本类型与输出

| 类别  | 常见类型                                    | 要点                                     | `printf`          |
| --- | --------------------------------------- | -------------------------------------- | ----------------- |
| 整数  | `char`、`short`、`int`、`long`、`long long` | `signed`/`unsigned` 改变可表示范围；具体位宽由实现决定。 | `%d`、`%ld`、`%lld` |
| 浮点  | `float`、`double`、`long double`          | 典型分别为 4/8/16 字节，但不可假设。                 | `%f`、`%Lf`        |
| 布尔  | `_Bool` / `bool`                        | `#include <stdbool.h>`；`0` 为假，任意非零为真。  | `%d`              |

- 源码字面量可写十进制、八进制（前缀 `0`）和十六进制（`0x`）；内存最终只保存位。
- 有符号整数溢出是**未定义行为**；无符号整数按其位宽模 `2^N` 回绕。
- 负数在主流平台通常使用补码；涉及位表示时，避免依赖具体机器表示。
- 需要固定宽度时使用 `<stdint.h>` 的 `int32_t`、`uint8_t` 等；只有实现支持对应精确宽度时该类型才存在。

## 2. 字符与字符串

```c
char c = 'A';
char name[] = "Ada";       // {'A', 'd', 'a', '\0'}，可修改
const char *title = "C";   // 字符串字面量，不应修改
```

- `char` 是整数类型；字符编码由执行字符集决定，常见为 ASCII/UTF-8 环境。
- C 字符串是以 `\0` 结束的 `char` 序列；容量必须为字符数加一。
- `sizeof name` 得到数组总字节数；`strlen(name)` 得到结束符前的字符数。

## 3. 标准输入

| API | 适合场景 | 关键规则 |
| --- | --- | --- |
| `scanf` | 格式严格的简单输入 | 非数组变量传地址；检查返回值；格式串末尾不要随意写空白或 `\n`。 |
| `fgets` | 读取整行文本 | 传入缓冲区和容量；可能保留换行；成功后再解析。 |

```c
int age;
if (scanf("%d", &age) != 1) {
    /* 输入不是一个 int，处理错误 */
}
```

`scanf` 匹配失败时，未匹配字符通常仍留在输入流中；不要假定它会自动清空错误输入。

## 4. 转换与可移植性

- **隐式转换**由表达式规则触发；小整数常先提升为 `int` 或 `unsigned int`。
- **强制转换**写作 `(type)expr`，仅改变本次求值的解释或结果；可能截断、溢出或丢失精度。
- 标准仅保证整数类型的相对最小范围，不保证 `int`、`long` 的固定大小。跨平台接口优先使用 `<stdint.h>`、`size_t` 与正确格式说明符。

## 5. 运算符

| 类别 | 要点 |
| --- | --- |
| 算术 `+ - * / %` | `%` 仅用于整数；整数除法截断向零。 |
| 自增/自减 `++ --` | 前缀先变后取值，后缀先取值后变；同一表达式中避免对同一对象多次修改。 |
| 比较 `== != < <= > >=` | 结果为 `0` 或 `1`。 |
| 逻辑 `! && ||` | `&&`、`||` 从左到右短路求值。 |
| 位运算 `~ & | ^ << >>` | 操作整数位；对负数移位和越界移位不要依赖，右移负数的结果由实现定义。 |
| 条件 `?:` | 唯一三元运算符：`cond ? a : b`。 |
| `sizeof` | 得到对象/类型的字节数，结果类型为 `size_t`；多数情况下不求值其操作数。 |

赋值从右向左结合，`a = b = 0` 合法。数组不是可赋值对象，不能直接 `a = b`。

## 6. 控制流

```c
if (score >= 60) {
    pass();
} else {
    retry();
}

for (size_t i = 0; i < n; ++i) {
    work(i);
}
```

- `if` 按条件选择；将条件写完整，避免悬空 `else`。
- `switch` 的控制表达式须为整数或枚举类型；`case` 是整型常量表达式；`break` 防止贯穿执行。
- `while` 先判断，循环体可执行零次；`do { ... } while (cond);` 至少执行一次。
- `break` 离开最内层循环或 `switch`；`continue` 进入最内层循环的下一次迭代。
- `goto` 应限于清理多个资源的统一退出路径，避免构造难以追踪的流程。
