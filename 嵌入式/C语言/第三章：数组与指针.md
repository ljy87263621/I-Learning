# 数组与指针

[[欢迎|返回索引]]

## 1. 数组：连续、定长的同类对象

```c
int a[3] = {10, 20, 30};
a[1] = 99;
```

- 下标范围是 `0` 到 `长度 - 1`；越界访问是未定义行为。
- 数组整体不可赋值、不可作为函数返回值；可逐元素复制，或在满足条件时用 `memcpy`。
- 初始化未提供的元素补零；`int a[3] = {1};` 等价于 `{1, 0, 0}`。
- 多维数组按行连续存储；传参时除第一维外的维度必须可确定。

### 数组到指针的转换

除 `sizeof a`、`&a`、字符串数组初始化等少数语境外，数组表达式会转换为指向首元素的指针：

```c
int a[3];
int *p = a;       // 等价于 &a[0]
sizeof a;         // 整个数组的大小
&a;                // 指向整个数组：int (*)[3]
```

`a[i]` 等价于 `*(a + i)`，因此 `i[a]` 语法上合法但不应使用。

### 变长与柔性数组

- **变长数组（VLA）**：长度在定义时求值，之后固定；它是可选特性，嵌入式项目需确认编译器支持。
- **柔性数组成员**：结构体最后一个成员写作 `type data[];`，其存储空间需额外分配。`data[0]` 是 GNU 扩展，不是标准 C 的柔性数组写法。

## 2. 指针：保存地址的对象

```c
int value = 42;
int *p = &value;  // & 取地址
*p = 7;           // * 解引用，修改 value
```

指针类型描述其目标类型，决定解引用方式和指针算术步长。所有对象指针在同一平台上常有相同大小，但语言层面应通过 `sizeof` 获取，不写死数值。

### 指针算术

`p + 1` 移动一个目标元素，而非一个字节。它只在**同一数组对象**范围内（含尾后位置）才有定义；尾后指针可比较，不可解引用。

```c
int a[3] = {0};
int *end = a + 3;       // 合法，但不能 *end
for (int *it = a; it != end; ++it) {
    *it += 1;
}
```

## 3. 空指针、悬垂指针与野指针

| 名称 | 含义 | 处理原则 |
| --- | --- | --- |
| 空指针 | 不指向对象或函数的特殊指针值，写作 `NULL` 或 `0` | 可比较、可传递；**不可解引用**。 |
| 悬垂指针 | 曾指向的对象已结束生命周期，例如 `free` 后 | 立即停止使用；可设为 `NULL`。 |
| 未初始化指针 | 值不确定 | 初始化为有效地址或 `NULL` 后再使用。 |

空指针并不要求其机器表示全为零；“检查非空”也不能证明其一定指向有效对象。

## 4. 常见指针形式

| 声明 | 含义 |
| --- | --- |
| `const int *p` | 不能通过 `p` 修改目标；`p` 本身可改指向。 |
| `int *const p = &x` | 指针不可改指向；可修改目标。 |
| `const int *const p = &x` | 指针与目标都不可经由 `p` 修改。 |
| `void *p` | 通用对象指针；解引用前必须转换为具体对象指针。 |
| `int **pp` | 指向 `int *` 的指针。 |

`void *` 不是“无类型内存”；它只是不携带具体对象类型。标准 C 不允许对 `void *` 直接解引用或做指针算术。

## 5. 函数指针

函数指针用于回调，其类型必须与目标函数签名兼容：

```c
int compare(const void *left, const void *right);
int (*cmp)(const void *, const void *) = compare;
```

函数名在多数表达式中会转换为函数指针；调用时 `cmp(a, b)` 与 `(*cmp)(a, b)` 等价。

## 易错点

- 不能返回局部数组或局部变量的地址。
- 字符串字面量通常不可修改，应用 `const char *` 接收。
- 将不相关的对象指针强转后解引用，可能违反对齐和有效类型规则，属于未定义行为。
