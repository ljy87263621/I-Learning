## 1. 定义、声明与调用

```c
/* 声明：告诉编译器接口 */
int add(int left, int right);

/* 定义：提供实现 */
int add(int left, int right) {
    return left + right;
}

int sum = add(2, 3);
```

| 概念 | 要点 |
| --- | --- |
| 声明 | 给出函数名、参数类型和返回类型；可重复且应保持兼容。函数原型中的参数名可省略。 |
| 定义 | 只能有一个定义，包含函数体。 |
| 调用 | 实参数量与类型须与声明兼容；调用表达式的值是返回值。 |
| `void` | 参数列表中的 `void` 表示不接收参数；返回类型为 `void` 表示不返回值。 |

C 采用**值传递**：形参是实参值的副本。需要让函数修改调用者对象时，传入其地址。

```c
void swap(int *left, int *right) {
    int temp = *left;
    *left = *right;
    *right = temp;
}
```

## 2. 栈帧与局部对象

函数调用通常为参数和局部自动对象建立栈帧；函数返回后这些对象的生命周期结束。因此不能返回局部对象的地址：

```c
int *bad(void) {
    int local = 1;
    return &local;  // 错误：返回后 local 已失效
}
```

栈的具体增长方向、参数传递方式由 ABI 决定，不应写入可移植程序逻辑。大对象不宜放在栈上，以免栈溢出。

## 3. `static`、递归与内联

| 写法 | 效果 |
| --- | --- |
| `static int helper(...)`（文件作用域） | 内部链接：仅当前源文件可见。 |
| `static int count;`（块作用域） | 静态存储期：只初始化一次，整个程序运行期间存在；作用域仍是该代码块。 |
| `static inline ...` | 建议内联且限制在当前编译单元；是否真正内联由编译器决定。 |

递归必须同时具备**终止条件**和**规模缩小**。深度受栈容量限制；可迭代时，迭代通常更省栈。

```c
unsigned factorial(unsigned n) {
    return n <= 1 ? 1 : n * factorial(n - 1);
}
```

## 4. 回调与函数指针

回调把“何时调用”交给框架，把“做什么”交给使用者：

```c
typedef void (*handler_t)(int event);

void dispatch(handler_t handler, int event) {
    if (handler != NULL) {
        handler(event);
    }
}
```

确保回调签名匹配，并明确回调执行期间传入对象的有效期与线程/中断上下文。

## 5. 字符串 API

所有下列字符串函数均定义于 `<string.h>`，并要求输入是有效的 `\0` 结尾字符串。

| 函数 | 作用 | 边界/副作用 |
| --- | --- | --- |
| `strlen(s)` | 返回结束符前长度 | 不含 `\0`；`s` 必须有效。 |
| `strchr(s, c)` / `strrchr` | 查找首次/末次字符 | 查找 `\0` 合法。 |
| `strstr(s, sub)` | 查找子串 | 成功返回子串首地址，否则 `NULL`。 |
| `strcmp(a, b)` / `strncmp` | 字典序比较 | 结果 `< 0`、`0`、`> 0`，不要假定恰为 `-1/0/1`。 |
| `strcpy(dst, src)` | 复制字符串 | `dst` 容量必须足够；源/目标不得重叠。 |
| `strcat(dst, src)` | 拼接字符串 | `dst` 必须已有终止符且总容量足够。 |
| `strtok(s, delim)` | 分词 | 修改原字符串且维护内部状态；嵌套/并发场景不适用。 |

`strncpy` 与 `strncat` 并不自动解决所有边界问题：前者可能不写终止符，后者的长度参数不是目标缓冲区总容量。优先显式计算剩余容量，或在可用平台采用更安全的封装。

## 6. 编译器扩展：弱符号

GNU 工具链可用 `__attribute__((weak))` 提供可被强符号替代的默认实现：

```c
void board_init(void) __attribute__((weak));
void board_init(void) {}
```

这是**非标准 C 扩展**；跨工具链项目需隔离在平台适配层中。
